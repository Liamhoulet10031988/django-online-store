# Интернет-магазин на Django

## Описание

Проект продолжает развиваться на протяжении блока Django.

На текущем этапе настроен Django-проект, создано приложение `catalog`, добавлены
главная страница и страница контактов с Bootstrap-оформлением.

## Реализовано

- Django-проект с пакетом конфигурации `config`;
- приложение `catalog`;
- главная страница интернет-магазина;
- страница контактов;
- маршрутизация через `catalog/urls.py`;
- подключение маршрутов приложения через `include()`;
- HTML-шаблоны;
- локальные статические файлы Bootstrap;
- форма обратной связи с CSRF-защитой;
- обработка POST-запроса формы.

## Структура проекта

```text
config/                     - настройки и главные маршруты Django
catalog/                    - приложение интернет-магазина
catalog/templates/catalog/  - HTML-шаблоны приложения
static/                     - CSS, JavaScript и изображения
manage.py                   - управление Django-проектом
pyproject.toml              - описание проекта и зависимости Poetry
```
## Запуск

```bash
poetry run python manage.py runserver
```

После запуска доступны страницы:

```text
http://127.0.0.1:8000/
http://127.0.0.1:8000/contacts/
```

## Проверка проекта

```bash
poetry run python manage.py check
```
