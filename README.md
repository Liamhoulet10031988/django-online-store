# Интернет-магазин на Bootstrap

## Описание

В проекте сверстаны четыре страницы интернет-магазина с использованием
Bootstrap 5. Также реализован простой HTTP-сервер на Python, который возвращает
страницу контактов и принимает данные формы.

## Реализовано

- главная страница с карточками товаров;
- страница каталога;
- страница категории;
- страница контактов с формой;
- адаптивная сетка Bootstrap;
- обработка GET-запросов;
- обработка POST-запроса формы;
- вывод принятых данных в консоль;
- HTML-страница ошибки 500, если файл контактов не найден.

## Структура

```text
index.html    - главная страница
catalog.html  - каталог
category.html - категория товаров
contacts.html - контакты и форма обратной связи
main.py       - простой HTTP-сервер

## Запуск

```bash
python main.py
```

После запуска открываем:

```text
http://localhost:8080
```

Сервер возвращает страницу `Контакты` на любой GET-запрос. После отправки формы
принятые данные выводятся в терминал.

## Использованные технологии

- Python;
- HTML5;
- Bootstrap 5;
- стандартная библиотека `http.server`.
