# Интернет-магазин на Django

## Описание

Учебный интернет-магазин на Django, который развивается в рамках курса
Python-разработки. Проект хранит товары, категории, контактные данные и статьи
блога в PostgreSQL.

Каталог и блог работают через классовые контроллеры Django. Для статей
реализованы создание, просмотр, изменение и удаление, фильтрация по признаку
публикации и счетчик просмотров.

## Реализовано

- Django-проект с приложениями `catalog` и `blog`;
- подключение PostgreSQL через переменные окружения;
- модели категорий, товаров, контактов и статей;
- загрузка изображений товаров и превью статей;
- миграции базы данных;
- административная панель для каталога;
- фикстуры категорий и товаров;
- команда загрузки тестовых товаров;
- классовые контроллеры CBV для страниц каталога;
- список товаров с пагинацией;
- подробная страница товара;
- форма создания товара;
- страница контактов с обработкой формы;
- полный CRUD статей блога через CBV;
- вывод только опубликованных статей;
- увеличение счетчика просмотров статьи;
- перенаправление на статью после изменения;
- письмо при достижении статьей 100 просмотров;
- базовый шаблон и общее меню;
- локальные стили Bootstrap 5.
- отдельная `ModelForm` для товаров;
- создание, просмотр, изменение и удаление товаров;
- проверка запрещённых слов в названии и описании;
- проверка отрицательной цены;
- проверка формата и размера изображений;
- стилизация полей формы через виджеты Django;

## Структура проекта

```text
config/                         - настройки и главные маршруты Django
catalog/                        - каталог товаров и страница контактов
blog/                           - статьи блога и CRUD-контроллеры
catalog/migrations/             - миграции моделей каталога
blog/migrations/                - миграции модели блога
catalog/fixtures/               - данные категорий и товаров в JSON
catalog/management/commands/    - собственные команды manage.py
catalog/templates/catalog/      - шаблоны каталога и базовый шаблон
blog/templates/blog/            - шаблоны блога
static/                         - локальные файлы Bootstrap
media/                          - загруженные изображения, не хранится в Git
manage.py                       - управление Django-проектом
pyproject.toml                  - зависимости и настройки Poetry
.env.example                    - безопасный пример переменных окружения
```

## Установка

Установить зависимости:

```bash
poetry install
```

Создать PostgreSQL-базу `django_online_store`.

Создать `.env` по примеру `.env.example` и указать свои данные PostgreSQL и
SMTP. Настоящие пароли не должны попадать в Git.

Применить миграции:

```bash
poetry run python manage.py migrate
```

При необходимости загрузить товары и категории:

```bash
poetry run python manage.py load_products
```

## Запуск

```bash
poetry run python manage.py runserver
```

Основные страницы:

```text
http://127.0.0.1:8000/
http://127.0.0.1:8000/products/create/
http://127.0.0.1:8000/contacts/
http://127.0.0.1:8000/blogs/
http://127.0.0.1:8000/blogs/create/
http://127.0.0.1:8000/admin/
```

## Проверка проекта

```bash
poetry run python manage.py check
poetry run python manage.py makemigrations --check
poetry run flake8 .
poetry run isort --check-only .
```
